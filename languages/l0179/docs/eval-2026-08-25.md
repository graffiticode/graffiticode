# L0179 evaluation, 2026-08-25

Two sweeps, run the day the corpus was built. Recorded here rather than in the console's
`MODEL_PRIORITY` table because L0179 is `hidden` and does not route: a priority line would be
inert, and that table's rule is that every entry cites the eval justifying it. When L0179 takes
over routing from L0166, this is the evidence for the line.

## Setup

- Corpus: 107 examples, generated batch-by-batch from `spec/examples.md` with each batch gated
  and embedded before the next generated (so batch N retrieved batches 1…N-1).
- Cases: 12 per set, authored from the public MCP surface, hold-out gate clean on both.
- Models: haiku-4.5, gpt-5.6-luna, sonnet-5, gpt-5.6-terra. 3 trials, 144 runs per sweep.
- Dialect `a3552541dd06` (12,572 bytes of instructions, against L0166's 15,818).

## Sweep 2 — L0166's cases against L0179 (`data/model-eval/cross/0179.json`)

## What it says, and what it does not

**The style neither helps nor hurts generation rate.** Both languages are at the compile ceiling
on these prompts. Luna's 92% → 100% is 3 failures in 36 and inside noise; it is not a win to
claim. Cost is a wash, marginally favouring L0166 on three of four models — plausibly because
L0179's cases retrieved slightly more examples (1.92 vs 1.75 per case), which outweighs its 21%
smaller instructions.

**So the case for L0179 is not in these numbers.** What it bought is invisible to a compile-rate
sweep, because every item here is a defect the old language accepts silently:

- per-container attribute sets reject a misplaced attribute that L0166 merges into a record
  nothing reads;
- 15 argument-type checks, `points`, and the no-cells rule are compile errors rather than
  silently dropped values;
- L0166's own corpus contains `{"fontWeight": "bold"}` on header cells — a header that never
  renders bold — which is inexpressible in L0179 and was rejected at translation.

A sweep measures whether a program compiles. It cannot measure whether a program that compiles
does what was asked, which is the axis these languages differ on.
