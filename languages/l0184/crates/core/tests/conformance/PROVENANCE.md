# Provenance of L0184's trusted TypeScript fixtures (interpreter plan A6, gate 5)

These files are the **last record of the TypeScript L0184's behavior**. The Rust implementation is
tested against them; they are never regenerated from the Rust and called parity. The TypeScript
source and the generator were removed on 2026-11-03 (A6); a deliberate language change now
updates them by hand, reviewed as a change to the language, and says so in its commit. To add a
case, parse its program with `@graffiticode/parser` against `lexicon()` and record the Rust's
output only after review.
