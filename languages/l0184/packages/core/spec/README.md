# L0184 spec

The documentation that drives L0184's code generation and describes the language: `spec.md`
(reference, rendered to `spec.html`), `instructions.md` (the generator's instructions),
`usage-guide.md`, `examples.md` (retrieval prompts), `scope.json`, `language-info.json`,
`schema.json` (the compiled output) and `template.gc`. Licensed CC-BY-4.0.
