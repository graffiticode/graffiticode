ISOLATE-01 · compiler egress

How a compiler reaches Policy, Broker and nothing else

Designed and coded in deploy/egress-proxy, not deployed

Every compiler runs on the compilers VPC with all outbound traffic sent to an internal load balancer at 10.8.0.2:3128, in front of two Envoy VMs. Envoy decides by the compiler's subnet (its class), terminates TLS only for Graffiticode's own run.app hosts, and refuses everything else. Broker is the only thing that ever talks to Learnosity, and it does so from outside the compiler network with its own sealed credential.

Allowed request Response TLS to Envoy (private-CA certificate) Refused

Three layers, each enforced without the compiler's help

1
VPC firewall
Compiler subnets may send only to the load balancer (and the metadata server). A compiler that ignores HTTPS_PROXY and dials an address directly is dropped here.
2
Envoy
The class is the filter chain matching the connection's direct source address, never a header. Listed hosts are terminated: the SNI picks the host, RBAC requires the CONNECT target to equal it, and the route accepts only that host as Host. Envoy then opens its own TLS to the real host and verifies its public certificate.
3
ENVOY_OUT and the proxy's firewall
Whatever a name resolved to, new connections from Envoy's UID 10101 can't reach private, loopback, metadata, CGNAT, Google private-access, compiler or load-balancer addresses. This is what stops L0185's open class reaching anything internal.

Refusals the proxy names

Every 403 carries x-isolate01-refused and one JSON log line.

ReasonWhen
unlistedA strict class names a host outside its network.allow list, Learnosity's included.
host-mismatchA terminated host's request carries a different Host or :authority: domain fronting through Google's shared front ends.
nameL0185's open class names learnosity.com, learnosity.net, run.app, internal or googleapis.com.
ip-literalThe open class names an address instead of a host.
portThe open class CONNECTs to any port but 443.
Hostnames are shortened: policy-….run.app stands for the Policy service's own run.app host, and the same for Broker. Classes today: compilers-default (10.8.16.0/22, strictly allowlisted) and compilers-l0185 (10.8.20.0/22, open, decision D2). Hosts per compiler come from deploy.json network.allow, which no service sets yet. Source: deploy/egress-proxy/README.md, classes.json and the ISOLATE-01 plan.
