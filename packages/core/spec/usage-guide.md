# Using L0183

## Overview

L0183 draws concept webs: a hub in the centre, nodes on a circle around it, and lines between
them that may carry labels such as "eaten by" or "causes". Any node, the hub included, and any
line can be made a blank that the learner fills by dragging an answer from a tray beside the web.
The tray is built from the answers themselves plus any wrong answers you ask for, so the answer
key and the tray can never disagree. Blanks that sit in interchangeable places accept each
other's answers, so a learner is never marked wrong for a correct arrangement. Webs are scored
with partial credit per blank, and the same web can be embedded in a Learnosity item through
L0176. Nodes can show text, math and images, and can be coloured, shaped and sized.

## Modes

| Mode | What to ask for | What you get |
| :--- | :-------------- | :----------- |
| Study web | "a concept web of …", "a mind map of …" | A labelled web with nothing to fill in |
| Fill the nodes | "students drag the terms onto the web", "leave the outer nodes blank" | Blank nodes and a tray of answers |
| Label the lines | "students label the relationships", "fill in the connecting words" | Blank edge labels and a tray of labels |
| Both | "blank nodes and blank relationships" | Two trays |

## Vocabulary Cues

| Say this | To get that |
| :------- | :---------- |
| "centre", "main idea", "central topic" | the `hub` |
| "around it", "branches", "connected ideas" | `nodes` |
| "arrow from A to B", "A leads to B" | an edge with `style "solid-arrow"` |
| "dotted line", "weaker link" | `style "dashed"` |
| "blank", "students fill in", "drag onto" | `assess [expected "…"]` |
| "wrong answers", "decoys", "extra options" | `distractors` |
| "put the word bank on the left" | `tray "left"` |
| "worth 2 points" | `points 2` |
| "dark mode" | `theme DARK` |

## Example Prompts

- "Make a concept web of the parts of a cell, with Nucleus given and three blanks for the students to fill."
- "Create a food chain web where students label each arrow, with one wrong label in the tray."
- "Build a study web of the causes of World War I, with each cause in a different colour."
- "A photosynthesis web where students drag the inputs and outputs onto blank nodes, the output worth 2 points."

## Out of Scope

- Flowcharts, timelines, trees and org charts — L0183 lays every web out as a hub and a circle.
- Learners adding nodes or lines of their own is not built yet.
- Venn diagrams are L0171. Multiple choice and other question types are L0180, or L0176 for Learnosity.
